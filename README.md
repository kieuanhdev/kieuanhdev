## Featured projects

### [EnglishMe](https://github.com/kieuanhdev/english_me_backend)

English-learning app: a Flutter client and a Spring Boot API (PostgreSQL, Firebase Admin) for lessons, vocabulary, grammar, pronunciation, and progress. [Flutter app](https://github.com/kieuanhdev/english_me_fontend)

### [e-commerce](https://github.com/kieuanhdev/e-commerce)

Flutter shop for Android and web, with Firebase Auth, Cloud Firestore, Cloudinary uploads, and BLoC.

### [e-commerce-backend](https://github.com/kieuanhdev/e-commerce-backend)

Spring Cloud services for users, products, cart, orders, inventory, and reviews, plus a Next.js storefront for catalog, cart, shipping, and payment forms. [Storefront](https://github.com/kieuanhdev/e-commerce-fontend)

### [Team Task Web](https://github.com/kieuanhdev/bot-jira)

Next.js board on top of Jira, with bulk edits, release checks, and notifications.

### [Trạm Truyện](https://github.com/kieuanhdev/tramtruyenweb)

Web-novel site: a Next.js reader for novels, chapters, and comments, backed by a Spring Boot API with JWT auth. [API](https://github.com/kieuanhdev/TramTruyenAPI)

### [ebook-reader](https://github.com/kieuanhdev/ebook-reader)

Flutter desktop reader for EPUB and PDF, with a local library and saved reading progress.

Other public work: [QLGym](https://github.com/kieuanhdev/QLGym) (C# gym desktop app), [4A_NET](https://github.com/kieuanhdev/4A_NET), [laptopshop](https://github.com/kieuanhdev/laptopshop) (Spring Boot), [CSE485Lab04](https://github.com/kieuanhdev/CSE485Lab04) (Laravel), [Runner2D](https://github.com/kieuanhdev/Runner2D) (Unity), and [IOT](https://github.com/kieuanhdev/IOT) (ESP32 waste sorting).
